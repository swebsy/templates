# Ashby — free portfolio website template

![Ashby](thumb.webp)

A newborn and family photographer's dark site: uncropped prints on a darkroom bench, each with a film-edge caption, laid out as one 36-frame roll.

Good for: Newborn photographers, Family photographers, Portrait studios.

- [Live demo](https://studio.swebsy.com/templates/ashby/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=ashby&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/ashby/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
