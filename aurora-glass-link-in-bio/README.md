# Aurora Glass — free link in bio website template

![Aurora Glass](thumb.webp)

A luminous glass link-in-bio template with social links, featured media, product cards, and an animated aurora background in light and dark modes.

Good for: Beauty creators, Lifestyle influencers, Product-focused personal brands.

- [Live demo](https://studio.swebsy.com/templates/aurora-glass-link-in-bio/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=aurora-glass-link-in-bio&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/aurora-glass-link-in-bio/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
