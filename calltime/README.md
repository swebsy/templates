# Calltime — free local business website template

![Calltime](thumb.webp)

A bridal hair and makeup website for a two-artist team: named weddings with ready-by times, a printed call sheet of the morning, every price, and a trial studio page.

Good for: Bridal makeup artists, Wedding hair stylists, Hair and makeup teams, Beauty and wedding professionals.

- [Live demo](https://studio.swebsy.com/templates/calltime/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=calltime&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/calltime/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
