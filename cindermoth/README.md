# Cindermoth — free other website template

![Cindermoth](thumb.webp)

A dark editorial launch and press-kit template for indie games, with cinematic galleries, store calls to action, support resources, and legal pages.

Good for: Indie game studios, Solo game developers, Narrative game launches, Game press kits.

- [Live demo](https://studio.swebsy.com/templates/cindermoth/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=cindermoth&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/cindermoth/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
