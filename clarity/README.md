# Clarity — free services website template

![Clarity](thumb.webp)

A polished advisory template for consultants and strategy firms to present their method, proof, workshops, and inquiry path with confidence.

Good for: Strategy consultants, Advisory firms, Workshop leaders.

- [Live demo](https://studio.swebsy.com/templates/clarity/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=clarity&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/clarity/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
