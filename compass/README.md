# Compass — free services website template

![Compass](thumb.webp)

A calm services template for executive, leadership, and career coaches to explain outcomes, compare pathways, and invite discovery calls.

Good for: Executive coaches, Career coaches, Leadership advisors.

- [Live demo](https://studio.swebsy.com/templates/compass/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=compass&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/compass/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
