# Folio — free portfolio website template

![Folio](thumb.webp)

A clean, single-page portfolio template that gives independent creators a direct way to introduce themselves and highlight selected work.

Good for: New designers, Creative students, Independent creators.

- [Live demo](https://studio.swebsy.com/templates/folio/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=folio&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/folio/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
