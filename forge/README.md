# Forge — free services website template

![Forge](thumb.webp)

A bold training website for coaches who build sustainable strength through real movement, honest progress, and focused one-to-one support.

Good for: Personal trainers, Strength coaches, Independent fitness studios.

- [Live demo](https://studio.swebsy.com/templates/forge/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=forge&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/forge/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
