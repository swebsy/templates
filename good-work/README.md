# Good Work — free nonprofit website template

![Good Work](thumb.webp)

A bold multi-page nonprofit template for community relief, transparent impact reporting, fundraising, volunteer opportunities, and human stories.

Good for: Community nonprofits, Relief organizations, Volunteer-led initiatives.

- [Live demo](https://studio.swebsy.com/templates/good-work/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=good-work&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/good-work/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
