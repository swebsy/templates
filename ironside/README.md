# Ironside — free local business website template

![Ironside](thumb.webp)

A bold neo-brutalist barbershop template with hard borders, offset shadows, expressive type, services, pricing, and booking details.

Good for: Barbershops, Independent barbers, Grooming studios.

- [Live demo](https://studio.swebsy.com/templates/ironside/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=ironside&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/ironside/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
