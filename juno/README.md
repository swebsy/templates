# Juno — free portfolio website template

![Juno](thumb.webp)

A colorful neo-brutalist portfolio template for creative makers who want to present projects, personality, and contact details with confidence.

Good for: Creative makers, Graphic designers, Digital artists.

- [Live demo](https://studio.swebsy.com/templates/juno/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=juno&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/juno/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
