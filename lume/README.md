# Lume — free portfolio website template

![Lume](thumb.webp)

A bright portfolio template for freelance UX and product designers to introduce their practice, selected work, services, and contact path.

Good for: UX designers, Product designers, Design freelancers.

- [Live demo](https://studio.swebsy.com/templates/lume/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=lume&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/lume/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
