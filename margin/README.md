# Margin — free services website template

![Margin](thumb.webp)

An independent tutor's site set like a marked exam paper: a margin rail, a worked answer marked M1 A0, the mark key, subjects, a free trial, results, fees and a booking form.

Good for: Private tutors, Teachers who coach one to one, Exam coaches.

- [Live demo](https://studio.swebsy.com/templates/margin/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=margin&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/margin/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
