# Marquee — free events website template

![Marquee](thumb.webp)

A photography-led conference site: full-bleed image plates, hairline-ruled schedules and ticket tiers, and a warm near-black ground that lets the pictures carry all the colour.

Good for: Conferences and festivals, Single-track events, Meetup and workshop series, Anyone with real photography to show.

- [Live demo](https://studio.swebsy.com/templates/marquee/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=marquee&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/marquee/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
