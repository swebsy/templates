# Morrow — free local business website template

![Morrow](thumb.webp)

A premium editorial website for residential landscape design-build studios, with immersive project storytelling, services, studio profile, and direct-contact conversion.

Good for: Landscape designers, Residential design-build studios, Garden construction firms.

- [Live demo](https://studio.swebsy.com/templates/morrow/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=morrow&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/morrow/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
