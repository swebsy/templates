# Nimbus — free saas website template

![Nimbus](thumb.webp)

An instrument-precise template for a hardware product and its app, with a full specification, a support hub with firmware release notes, a retailer directory and a warranty page.

Good for: Hardware brands, Smart home devices, Consumer electronics, Device companion apps, Products sold through retailers.

- [Live demo](https://studio.swebsy.com/templates/nimbus/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=nimbus&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/nimbus/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
