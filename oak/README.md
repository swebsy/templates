# Oak — free local business website template

![Oak](thumb.webp)

A warm, editorial multi-page pub and dining template with rich imagery, menus, events, venue information, and external reservations.

Good for: Independent pubs, Gastropubs, Neighbourhood restaurants, Dining rooms and bars.

- [Live demo](https://studio.swebsy.com/templates/oak/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=oak&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/oak/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
