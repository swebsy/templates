# Ocho Ventanas — free local business website template

![Ocho Ventanas](thumb.webp)

A small cliffside guesthouse where every photo is a window cut in a terracotta wall, drawn to true scale, with a building elevation as the room index.

Good for: Small hotels and guesthouses, Holiday rentals, Architects and builders showing a house.

- [Live demo](https://studio.swebsy.com/templates/ocho-ventanas/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=ocho-ventanas&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/ocho-ventanas/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
