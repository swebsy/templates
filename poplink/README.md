# Poplink — free link in bio website template

![Poplink](thumb.webp)

A bright, playful link-in-bio template that helps creators collect social profiles, featured content, and essential links on one memorable page.

Good for: Content creators, Online personalities, Creative freelancers.

- [Live demo](https://studio.swebsy.com/templates/poplink/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=poplink&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/poplink/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
