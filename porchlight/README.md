# Porchlight — free local business website template

![Porchlight](thumb.webp)

A real estate website for a small agent team: big house numbers, every sale on the record, neighborhood guides and a price-opinion form.

Good for: Real estate agents and realtors, Small real estate teams, Independent brokerages, Property and home sellers.

- [Live demo](https://studio.swebsy.com/templates/porchlight/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=porchlight&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/porchlight/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
