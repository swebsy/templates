# Pulsar — free saas website template

![Pulsar](thumb.webp)

A dark-first product site for developer tools and B2B SaaS, with a glowing centered hero, bento feature grid, logo wall, three-tier pricing and a changelog page.

Good for: Software teams, Startups.

- [Live demo](https://studio.swebsy.com/templates/pulsar/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=pulsar&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/pulsar/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
