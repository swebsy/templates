Changelog

What shipped, and when

Pulsar ships every week. Notes are drafted from the issues in the release, so this page is never a second version of the truth.

24 July 2026

v2.9

Agent runs, out of preview

Hand any issue to an agent and watch the run stream in beside the board. Runs carry the issue's context, and the diff lands as a pull request you can review in place.

  • Run history with full transcripts and token spend
  • Per-team spend caps and approval gates
  • MCP server so your own tools can queue runs

10 July 2026

v2.8

Release notes that write their first draft

Cutting a release now drafts public notes from the issues it carries — grouped, deduplicated, and in your product's voice rather than your commit log's.

  • Hosted public changelog with RSS
  • Scheduled publishing with an embargo window

26 June 2026

v2.7

Offline, properly

The whole workspace is local-first now. Triage on a plane, reconnect, and every change merges without a conflict dialog asking you to pick a winner.

  • Conflict-free sync for issues, comments, and views
  • Cold start down from 1.8s to 340ms

12 June 2026

v2.6

Initiatives and rolled-up progress

Roadmap items now derive their status from the issues underneath them, so the quarterly plan stops being a slide deck that quietly goes stale.

  • Shareable read-only roadmap links
  • Target dates that warn before they slip
