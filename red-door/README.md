# Red Door — free local business website template

![Red Door](thumb.webp)

A preschool site read down a doorframe: each section hangs at its real height, from the gate latch to the fee noticeboard to the skirting.

Good for: Preschools and kindergartens, Early childhood centres, Independent daycare owners.

- [Live demo](https://studio.swebsy.com/templates/red-door/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=red-door&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/red-door/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
