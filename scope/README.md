# Scope — free services website template

![Scope](thumb.webp)

A bold editorial studio template for fixed-scope brand and web services, with pricing, work, case study, studio, and inquiry pages.

Good for: Brand and web studios, Independent creative teams, Productized service businesses.

- [Live demo](https://studio.swebsy.com/templates/scope/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=scope&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/scope/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
