# Sixth Week — free services website template

![Sixth Week](thumb.webp)

A physio clinic site drawn as one 12-week recovery line, re-cropped per section, with visit counts and prices shown up front.

Good for: Physiotherapy clinics, Chiropractors and osteopaths, Sports rehab practices, Small health practices.

- [Live demo](https://studio.swebsy.com/templates/sixth-week/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=sixth-week&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/sixth-week/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
