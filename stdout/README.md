# Stdout — free other website template

![Stdout](thumb.webp)

A dark terminal-inspired developer tool template with product storytelling, pricing, changelog, legal, and conversion pages.

Good for: Independent professionals, Small organizations.

- [Live demo](https://studio.swebsy.com/templates/stdout/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=stdout&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/stdout/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
