# Twelve — free services website template

![Twelve](thumb.webp)

A two-partner accounting practice set as a wall planner: every CRA date filled in lime, the fixed fee in each month, your 22 minutes.

Good for: Accountants and bookkeepers, Tax preparers, Small professional practices.

- [Live demo](https://studio.swebsy.com/templates/twelve/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=twelve&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/twelve/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
