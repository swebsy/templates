# Vantage — free portfolio website template

![Vantage](thumb.webp)

A bold portfolio template for product designers, creative leads, and independent consultants who want to show work and strategic range.

Good for: Senior product designers, Creative leads, Independent consultants.

- [Live demo](https://studio.swebsy.com/templates/vantage/preview/)
- [Edit in Swebsy](https://studio.swebsy.com/create?template=vantage&ref=github), the free visual editor, no account needed
- [Template details](https://swebsy.com/templates/vantage/)

## Use it

`site/` is the whole website. Open `site/index.html` locally, or upload the
folder to any static host. Replace `site/robots.txt` rules as needed and add a
sitemap once you know your domain (Swebsy writes one when you set a Site URL).
